## 👋 About Me

I'm **Maher Ben Ammar**, a **Software Engineering student at ENIS — National Engineering School of Sfax**, passionate about building intelligent, scalable and secure software systems.

I enjoy turning ideas into complete solutions — from backend architectures and APIs to AI pipelines, mobile applications, distributed systems and cybersecurity platforms.

* 🚀 **Goal:** Build reliable, intelligent and scalable software systems
